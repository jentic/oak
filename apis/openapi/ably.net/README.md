# Ably — Control API — OpenAPI Spec (Jentic Public APIs)

**Vendor:** `ably.net` | **API:** `control` | **Version:** `v1`

The Ably Control API lets you manage your Ably account programmatically, including creating and configuring apps, managing keys, setting up rules, and querying usage.

## What you can do with this API

- Create, update, and delete Ably applications
- Manage API keys and their capabilities
- Configure integration rules (webhooks, queues, Firehose)
- Query account and app-level usage statistics
- Manage namespaces and channel rules

## Who uses this API

Platform teams and DevOps engineers use the Control API to automate Ably infrastructure provisioning, manage multi-tenant app configurations, and integrate Ably account management into CI/CD pipelines.

## Access

AI agents can access this spec via the [Jentic APIs](https://jentic.com) or the [Jentic MCP server](https://jentic.com).

**Documentation:** [ably.net API docs](https://ably.com/docs/api/control-api)
