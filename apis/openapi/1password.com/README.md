# 1Password — Events API — OpenAPI Spec (Jentic Public APIs)

**Vendor:** `1password.com` | **API:** `events` | **Version:** `1.2.0`

The 1Password Events API lets you retrieve sign-in attempts, item usage events, and audit actions from your 1Password account for security monitoring and compliance.

## What you can do with this API

- Retrieve sign-in attempt events across your account
- Monitor item usage activity for auditing purposes
- Track actions performed by team members
- Stream events to SIEM tools for security analysis
- Detect unauthorized access patterns in real time

## Who uses this API

Security teams and compliance engineers integrate the Events API with SIEM platforms (Splunk, Elastic, Datadog) to monitor access patterns and generate audit trails.

## Access

AI agents can access this spec via the [Jentic APIs](https://jentic.com) or the [Jentic MCP server](https://jentic.com).
