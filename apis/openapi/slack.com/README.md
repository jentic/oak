# Slack — OpenAPI Specs (Jentic Public APIs)

**Vendor:** `slack.com`

Slack is a messaging platform for team communication, file sharing, and workflow automation.

## APIs

| API | Description |
|-----|-------------|
| [Slack Web API](./main/) | Send messages, manage channels, upload files, and automate workspace administration in Slack. |
| [Slack AI Plugin](./openai/) | Search Slack messages by keyword query for use in AI-powered chat interfaces. |
