# Ably — Platform API — OpenAPI Spec (Jentic Public APIs)

**Vendor:** `ably.io` | **API:** `platform` | **Version:** `1.1.1`

The Ably Platform API provides RESTful access to Ably's realtime messaging infrastructure for publishing messages, managing channels, and retrieving presence and history data.

## What you can do with this API

- Publish messages to channels via REST
- Retrieve message history for any channel
- Query presence sets to see connected clients
- Manage channel metadata and enumeration
- Request authentication tokens for client-side use

## Who uses this API

Backend developers and platform engineers integrate the Ably Platform API to add realtime messaging, push notifications, and presence features to web and mobile applications.

## Access

AI agents can access this spec via the [Jentic APIs](https://jentic.com) or the [Jentic MCP server](https://jentic.com).
