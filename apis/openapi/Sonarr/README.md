# Sonarr — Sonarr API — OpenAPI Spec (Jentic Public APIs)

**Vendor:** `Sonarr` | **API:** `main` | **Version:** `3.0.0`

Sonarr is an open-source TV series collection manager; its API provides full control over TV show library management, episode tracking, and download automation.

## What you can do with this API

- Search for and add TV series to your collection
- Monitor episodes and manage season packs
- Configure download clients and indexers
- Track download queues and import history
- Set quality profiles and release group preferences

## Who uses this API

Home media enthusiasts and developers building automation tools use this API to manage TV libraries and integrate Sonarr with media servers like Plex, Emby, or Jellyfin.

## Access

AI agents can access this spec via the [Jentic APIs](https://jentic.com) or the [Jentic MCP server](https://jentic.com).
