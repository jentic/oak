# Atlassian — OpenAPI Specs (Jentic Public APIs)

**Vendor:** `atlassian.com`

Atlassian builds team collaboration tools including Jira for project tracking, Confluence for documentation, and FishEye for code repository search.

## APIs

| API | Description |
|-----|-------------|
| [FishEye REST API](./fisheye-rest-api/) | Query repositories, changesets, revision data, and search code across repositories. |
| [Jira Cloud REST API](./jira/) | Manage issues, projects, workflows, dashboards, and permissions in Atlassian Jira Cloud for software development and project tracking. |

## Use with Jentic

Give your agent access to Atlassian APIs through Jentic. Store your credentials once, scope the agent's access, and it handles the rest — search, inspect, execute. No secrets exposed.
