# Radarr — Radarr API — OpenAPI Spec (Jentic Public APIs)

**Vendor:** `Radarr` | **API:** `main` | **Version:** `3.0.0`

Radarr is an open-source movie collection manager; its API provides full control over movie library management, download client integration, and media organization.

## What you can do with this API

- Search for and add movies to your collection
- Manage download clients and indexer configurations
- Monitor download queues and history
- Organize movie files with custom naming and folder structures
- Configure quality profiles and release filters

## Who uses this API

Home media enthusiasts and developers building automation tools use this API to manage movie libraries and integrate Radarr with other media management systems like Plex, Emby, or Jellyfin.

## Access

AI agents can access this spec via the [Jentic APIs](https://jentic.com) or the [Jentic MCP server](https://jentic.com).
