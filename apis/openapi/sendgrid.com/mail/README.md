# Twilio SendGrid Mail API

Send transactional and marketing emails at scale with batch scheduling and delivery management.

| | |
|---|---|
| **Base URL** | `https://api.sendgrid.com` |
| **Version** | `1.0.0` |
| **Auth** | Bearer token |
| **Endpoints** | 3 operations |

## What you can build with this API

- Send single or bulk emails with templates, attachments, categories, and custom tracking settings
- Schedule email batches for future delivery and cancel or pause scheduled sends
- Retrieve batch status to monitor delivery progress of scheduled campaigns
