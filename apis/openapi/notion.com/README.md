# Notion — OpenAPI Spec (Jentic Public APIs)

**Vendor:** `notion.com`

Notion is a connected workspace where teams build notes, databases, tasks, and wikis in one tool.

## APIs

| API | Description |
|-----|-------------|
| [Notion API](./notion-api/) | Notion API for pages, databases, blocks, users, comments, files, and views. |

## Use with Jentic

Jentic sits between your agent and this API. The agent searches by intent, loads operation details, and executes — while credentials stay encrypted in the vault, isolated from the agent.
